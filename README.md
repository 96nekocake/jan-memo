# JANメモ

JANコードを連続でスキャンし、一覧をテキストでコピーするスマホアプリ。コピーした一覧をAIに渡して、商品名の検索や常備品リストの整理に使う。

## 起動手順

Node.js の LTS 版と npm を用意する。

```sh
npm ci
npx expo start
```

iOS / Android の Expo Go でターミナルの QR コードを読み取る。

開発時の確認コマンド:

```sh
npx tsc --noEmit
npx expo lint
npx expo-doctor
npm test -- --runInBand
```

ユニットテストは `*.test.ts` / `*.test.tsx` に追加する。

## 使い方

カメラの使用を許可し、EAN-13 / EAN-8 のバーコードをカメラに向ける。読み取ったコードは新しい順に一覧に追加される。

不正なコードは追加しない。同じコードを再度読み取っても一覧は増えない。追加時と重複時にはバイブと約1.5秒の通知が出る。同じコードが映り続けている間は通知もバイブも繰り返さない。コードごとに最後の検出から1.5秒以上途切れた後、再び読み取ったときだけ処理する。

カメラの許可を再要求できない場合は「設定を開く」から許可する。

一覧は端末内に自動保存し、次回起動時に復元する。1件削除・全消去の結果も保存する。読み込みや保存に失敗した場合は、表示される「再試行」を押す。

各行の「✕」で1件削除する。「全消去」は確認画面で「全消去」を選ぶと実行され、「キャンセル」では一覧を維持する。
