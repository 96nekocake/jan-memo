# JANメモ

JANコードを連続でスキャンし、一覧をテキストでコピーするスマホアプリ。

コピーした一覧をAIに渡して、商品名の検索や常備品リストの整理に使う。商品名の検索はAI側で行い、このアプリはJANコードを集めて渡すことだけをする。

開発中。

## できること

- 連続スキャン: カメラを向けると自動で読み取る。読み取り後も画面を閉じず、次を続けて読める
- 対応コード: EAN-13、EAN-8(JAN)。UPC-A、UPC-E にも対応する
- チェックデジットが合わないコードは一覧に追加しない
- すでに一覧にあるコードは追加しない(重複防止)
- 一覧は新しいものが先頭。1件ずつ削除でき、全消去は確認ダイアログつき
- 一覧は端末内に自動保存され、アプリを閉じても残る
- 出力は「コードのみコピー」「AI向けコピー」「共有」の3つ
- カメラのライトの入り切り、表示中の自動消灯の防止
- 縦向き・横向きの両対応

通信はしない。アカウントやサーバーは持たず、データは端末内にだけ保存される。

個数は数えない。同じ物を複数読んでも、一覧には1行だけ載る。

## 使い方

1. カメラをバーコードに向ける。読み取ったコードが一覧の先頭に追加される
2. 続けて次のバーコードを向ける。そのまま連続で読み取れる
3. 「コードのみコピー」「AI向けコピー」「共有」のいずれかで、一覧をテキストとして取り出す

## 出力形式

どちらも1行1コードのプレーンテキスト。

コードのみコピー:

```text
4901234567894
4987654321094
```

AI向けコピー(前置き文 + 空行 + コード一覧):

```text
以下は家にある常備品のJANコード一覧です。
各コードをWebで検索して商品名を調べ、カテゴリ別の常備品リストにまとめてください。
検索しても見つからないコードは、推測せず「不明」と書いてください。

4901234567894
4987654321094
```
